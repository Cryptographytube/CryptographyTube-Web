# CryptographyTube

Static website files for cryptographytube.org

## Deployment

### cPanel Hosting
1. Login to cPanel → File Manager
2. Go to `public_html` folder
3. Upload all files from this folder
4. Done! Site is live.

### GitHub Pages
1. Push this folder to GitHub repository
2. Go to repo Settings → Pages
3. Select "Deploy from branch" → main → / (root)
4. Done! Site is live at `https://username.github.io/repo-name`

### Netlify
1. Go to https://app.netlify.com/drop
2. Drag this folder to the drop zone
3. Done! Site is live.

## Future Development

Monero API, RPC, and Node integration are not currently available. These features are planned for future development and may be added in upcoming updates.

## Official Websites

This source code is used for all three official CryptographyTube websites:

- https://cryptographytube.org/
- https://cryptographytube.com/
- https://cryptographytube.in/

All three websites use the same source code and are designed for deployment on cPanel hosting.

This project is open-source to promote transparency, security, and community contributions. Everyone is welcome to review, audit, and improve the source code to help keep the websites safe, secure, and reliable.
